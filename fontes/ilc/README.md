# ILC (Interface por Linha de Comando)

Aqui são implementados uma série de comandos para facilitar a interação com o banco de dados, especialmente durante o desenvolvimento e testes. Esses comandos incluem:

- `ilc semear`: Executa as sementes para popular o banco de dados com dados de teste
- `ilc limpar`: Limpa o banco de dados, removendo todas as tabelas
